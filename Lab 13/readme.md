# Machine Learning Mini Projects

## About
This project contains 5 machine learning tasks based on real-world scenarios.

The project uses:
- K-Means Clustering
- PCA
- Neural Networks

---

# Projects Included

## 1. Airline Customer Segmentation
Customers are grouped based on booking and spending behavior.

Technique Used:
- K-Means Clustering

---

## 2. Parkinson’s Disease Prediction
Voice data is analyzed to detect Parkinson’s disease.

Techniques Used:
- PCA
- ANN

---

## 3. Credit Card Fraud Detection
Transactions are classified as fraud or genuine.

Techniques Used:
- PCA
- Neural Network

---

## 4. Retail Customer Trend Analysis
Retail customer behavior is analyzed using clustering.

Techniques Used:
- PCA
- K-Means

---

## 5. Smart Manufacturing Defect Detection
Products are classified as pass or defect using ANN.

Technique Used:
- Artificial Neural Network
