
---

This project contains simple and easy-to-understand examples of machine learning techniques.

The goal of this project is to learn:
- Data Scaling
- Auto-Correlation
- Feature Importance
- Logistic Regression
- Random Forest

---

# Project Cases

## Case 1 — Healthcare
We normalize patient medical data before prediction.

Techniques:
- StandardScaler
- Logistic Regression

---

## Case 2 — Agriculture
We analyze crop yield patterns over time using auto-correlation.

Techniques:
- Time-Series Analysis
- Auto-Correlation

---

## Case 3 — Finance
We predict loan approval and calculate feature importance.

Techniques:
- Logistic Regression
- Feature Weighting

---

## Case 4 — Manufacturing
We detect unusual machine behavior using vibration sensor data.

Techniques:
- Auto Scaling
- Auto-Correlation

---

## Case 5 — Cybersecurity
We detect intrusion patterns in network traffic.

Techniques:
- Random Forest
- Feature Importance
- Scaling
